# External Literature INDEX — CASPER PhD

All 90 entries in `new_chapters/references.bib`, sorted by topic-tag then year.
Takeaways are drawn ONLY from the project's own summary/deep-research sources (see `README.md`);
papers not discussed anywhere carry `(citation only — not yet summarized)`. Bib-keys are preserved
so every claim is traceable. `relevant-to` = which CASPER paper (A/B/C/D/E) the finding feeds; `—` = none/background.

## Tag legend
- **cont-RL** — continuous-action / deep RL methods (DDPG, DQN, Wolpertinger, TD3, SAC, ECoC)
- **CRS-classic** — pre-LLM conversational recommender systems and adaptive dialogue strategies
- **CRS-LLM** — LLM-based conversational recommenders (2022–2025)
- **CRS-RL** — RL / graph policy learning for CRS (EAR, SCPR, UNICORN, PPDPP, RSO, ConTS)
- **CRS-survey** — surveys / reviews of the CRS field
- **elicit-AL** — rating elicitation, active learning, cold-start interview trees
- **elicit-belief** — Bayesian belief / VoI / info-gain preference elicitation
- **embed-infra** — embedding & retrieval infrastructure (SBERT, FAISS)
- **rec-model** — recommender models & evaluation methodology (MF, VAE, FM, top-N eval)
- **bot-play** — self-supervised bot-play / multi-agent dialogue RL
- **behav** — behavioral / choice psychology
- **misc** — datasets, template, non-research
