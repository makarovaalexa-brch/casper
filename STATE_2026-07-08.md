## 0. THE WORKING RULE (owner, 2026-07-07, adopted)
Adaptivity MUST work — a human interviewer is obviously adaptive. If our experiments show a tie, the
DEFAULT interpretation is that the arena/method/assumptions are broken, and we diagnose (as with the
E0f canary and the Phase-4 averaging bug — both found this way). "Adaptivity doesn't help" is not a
publishable endpoint; either we show it working, or we show precisely WHAT in the environment decides
whether it can (a boundary/law), which is a positive result. Never ship the shrug.

## 3. OPEN DESIGN TRUTHS (the owner's corrections, 2026-07-07 — the redesign constraints)
1. **Answerability is the ANSWERER's property**; the agent may only ESTIMATE it online (answers,
   refusals). Precomputed p̂ from true-profile genre_match = privileged; label it or estimate online.
2. **Open recall ≠ item probing** — separate channels: probing = system picks item, answerability
   binds, needs p̂; open recall = user volunteers, always answerable, high value, but CAPPED
   (~2–4 realistic per Paper D) and needs a proper LLM/fitted RECALL MODEL (which titles surface, in
   what order, when do users dry up) — |rating| ordering is a stand-in assumption. TODO: recall model.
3. **Answerer sees its ratings and can infer about unrated items** (LLM-predicted, sensitivity-only);
   agent starts blind, cold, and feels its way. That asymmetry is the deployability definition.
4. **All channels up for grabs**: items (probe), open recall, concepts, attributes (decade+genre in;
   actors/directors need external metadata join — TODO), pairs (built in earlier papers, not yet in
   the I2.5 arena — TODO), free-vocab LLM questions (not in arena — TODO/maybe).
5. **The fair baseline is the best static WITH item access** (mixed greedy), not concept-only.
6. **The learnable-policy ambition** (owner's belief #1): a LEARNED policy that naturally exhibits
   coarse→fine. History: 8+ learned attempts tied constructed schedules (optimization gap). Path:
   constructed decision-theoretic policy first; learned version only to close a measured gap to the
   privileged ceiling. Emergence evidence exists (E0e: marginal-info selector switches channels at
   exactly concept-saturation turn ~4, untrained).
